# passdown-addin

The public launcher for the Passdown Outlook add-in, served by GitHub Pages.
It holds no data and no token. The files at the root are built by
`apps/outlook-addin` in the passdown source repository
(`npm run build -w apps/outlook-addin`, then copy `dist/launcher/` here).

`pages/` is the earlier hosting test and can be deleted once nobody runs it.
